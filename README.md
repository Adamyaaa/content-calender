# 🚀 Company Content Calendar & Publishing Command Center

A ready-to-run, end-to-end Content Calendar & Publishing System built for your company's multi-channel growth.

---

## ⚡ Quick Start

### Option 1: Instant Launch (Zero Installation)
Simply double-click [`index.html`](file:///c:/dev/content%20calender/index.html) in your file explorer to open it immediately in Google Chrome, Edge, or any browser.

### Option 2: Local Web Server
You can also run a local server via npm or python:

```bash
# Using Python
python -m http.server 8080

# Or using Node / npm
npm start
# or: npx serve . -p 8080
```
Then visit: `http://localhost:8080`

## 🎯 Key Features Built-In

1. **Multi-View Command Center**:
   - **📅 Monthly Calendar**: Interactive grid with day-by-day scheduled posts, platform badges, and 1-click addition.
   - **📋 Kanban Workflow Board**: Drag-and-drop posts between any of the 5 production columns (*Idea* ➔ *Drafting* ➔ *In Review* ➔ *Ready / Scheduled* ➔ *Published*) with live column highlight feedback and quick 1-click step buttons.
   - **📑 List / Table View**: Fast search, filtering by channel, status, and pillar.
   - **🎯 Strategy & Pillar Balancer**: Live allocation bars tracking your output against the 40-30-20-10 rule.
2. **✨ Built-In AI Copywriter & Assistant**:
   - Generate high-converting hooks, captions, CTAs, and hashtags directly inside the post editor.
   - 5 copywriting frameworks: *Problem-Agitate-Solve (PAS)*, *Contrarian / Thought Leadership*, *Step-by-Step Educational*, *Customer Story*, and *Punchy*.
3. **📅 1-Click 30-Day Auto Planner**:
   - Automatically schedules a balanced multi-week publishing campaign across LinkedIn, X, Instagram, YouTube, and Newsletters.
4. **⚙️ Company & Team Profile Settings**:
   - Customize your company name, industry niche badge, tagline, and custom team members list (which automatically populates the Assignee dropdown).
5. **Platform-Aware Composer**:
   - Real-time character limit warnings (280 for X/Twitter, 3,000 for LinkedIn, 2,200 for Instagram).
   - Asset format tracking (Carousels, Short Videos/Reels, Infographics).
6. **Data Persistence & Portability**:
   - LocalStorage auto-save for continuous offline work.
   - **Export to CSV** for Google Sheets / Excel reporting.
   - **JSON Backup & Restore** for syncing across machines.
   - **Print / PDF Export** for executive presentations.
